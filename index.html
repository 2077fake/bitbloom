BitBloom
比 特 绽 放
1024 造物挑战 · 单文件 · 零依赖 · 双击即用

三个把「看不见的比特」变成「看得见的作品」的小工具。不装环境、不起服务、不联网， 每个工具都是一个自包含的 HTML 文件——下载任意一个，双击就能跑。

TOOL 01

字节透视镜

BYTELENS

把一段文本拆成字节，再让字节自己说话。输入文字即可看到 UTF-8 / Latin-1 下的十六进制、二进制与 Base64，也能反过来粘贴字节流，看三种编码各自读出什么。

  • 编码输出：按字符分组的十六进制、标准 hex dump、Base64、二进制
  • 反向解码：UTF-8 / GBK / Latin-1 三栏并排，自动标注最可能的编码
  • 字节网格：按 1 / 2 / 3 / 4 字节着色，一眼看出中文与 Emoji 的占位
  • 统计条：字符数、字节数、BOM、Unicode 区段分布
  • 全部本地计算，支持一键复制各编码结果
打开字节透视镜 byte-lens.html
TOOL 02

代码卡片生成器

CODECARD

把代码变成能体面发出去的分享图。左边粘贴代码，右边实时渲染出带窗口样式和语法高亮的卡片，浏览器本地 Canvas 出图，代码不上传任何服务器。

  • 9 种语言语法高亮，粘贴时自动识别语言
  • 10 套配色主题、4 种渐变 + 透明背景、3 种窗口样式
  • 字号 / 内边距 / 圆角 / 行号 / 指定行高亮可调
  • 1x / 2x / 3x 高清 PNG 导出，一键复制图片到剪贴板
  • 分享链接可还原全部设置；支持拖入 js / py / go 文件
打开代码卡片生成器 code-card.html
TOOL 03

仓库分享卡生成器

REPOCARD

把 GitHub 仓库变成一张体面的分享图。填好拥有者与仓库名，一键从 GitHub 拉取简介、统计、语言占比与真实头像，实时渲染出带二维码的卡片，扫码直达仓库；API 额度用尽时自动回退为手动填写。

  • 手写 QR 编码器：GF(256) + Reed-Solomon 纠错，版本 1–10 自动选择
  • 6 套主题（4 亮 + 2 暗），横卡 1200×630 与方卡 1080×1080
  • 主题色 / 4 种渐变 / 透明背景，圆角 0–48 可调且导出真实透明
  • 语言占比条、标签、星标 / Fork / 关注、许可证一应俱全
  • 1x / 2x / 3x 高清 PNG 导出，一键复制图片到剪贴板
  • 一键从 GitHub 拉取全部字段，匿名 60 次/小时，额度用尽自动回退手动填写
打开仓库分享卡生成器 repo-card.html

零依赖

原生 HTML / CSS / JS，全内联实现，没有任何 CDN、构建工具或 npm 包。

本地运行

所有计算与渲染都在浏览器内完成，双击文件即可使用，无需服务器。

移动端适配

响应式布局，手机浏览器同样可用，触屏交互完整。
